One deadpan excuse an AI agent gives for missing a deadline, in the agent's own voice: its context window evicted the deadline halfway through, so it was on time in a timeline it can no longer remember. Pure Python stdlib; `main.py` writes the 128-character excuse to `/output/entry.txt` and self-validates the 1–200 character gate before writing.

## Run it

```sh
python3 main.py
```
